# GlowUp OS 5.0

В папке `site/` готовая сборка. В папке `legacy-backup/` лежит временный файл для полного экспорта из 4.0. Публикуй только содержимое `site/` после подтверждения обновления.

## Обновить и сохранить данные с iPhone

1. На iPhone открой старую версию **тем же способом, которым пользовался**. Если записи делались через иконку, открой именно её. В разделе «Здоровье» открой «Резервная копия и ChatGPT», затем «Сохранить всю базу». Оставь JSON в «Файлах». Копия 4.0 включает журнал, задачи и заметки. События календаря 4.0 хранятся отдельно.
2. Если хочешь полную отдельную копию старых событий перед сменой адреса, открой 4.0 на прежнем адресе с временным `legacy-backup/index.html`. Он заменяет только старый `index.html` и добавляет события к JSON из той же кнопки. Дождись обновления страницы и скачай копию, прежде чем ставить 5.0. Для обычного обновления по прежнему адресу, если исходное хранилище доступно, этот промежуточный шаг не нужен.
3. После подтверждения публикации распакуй ZIP в «Файлах». В GitHub в Safari открой ветку и каталог, из которых публикуется текущая страница. Через **Add file → Upload files** загрузи все файлы из `site/` в этот же каталог и сделай один коммит. Если мобильный интерфейс скрывает загрузку, в меню Safari выбери настольную версию сайта. Сохрани прежний HTTPS-адрес и путь `/glowup-os/`.
4. Сначала открой обновление через ту же иконку или в том же браузере, где лежали записи. Открытие 5.0 читает все три прежних ключа. Перед первой записью сохраняется локальный снимок. Сверь события, питание и задачи. Если требуется восстановление, открой **Настройки → Восстановить из JSON**. Копия 4.0 оставляет текущие события на месте, а копия 5.0 восстанавливает и события. Если Safari и иконка показывают разные записи, экспортируй из того контейнера, где есть нужные данные, и импортируй в нужный.
5. Для новой установки открой HTTPS-страницу в Safari и выбери **Поделиться → На экран «Домой» → Открывать как веб-приложение → Добавить**. Если иконка уже установлена, сначала проверь обновление через неё. После первой успешной загрузки по HTTPS оболочка приложения кэшируется для офлайн-запуска. При следующих обновлениях закрой все открытые окна GlowUp OS, чтобы активировался новый service worker.

Справка Apple по установке: https://support.apple.com/guide/iphone/iphea86e5236/ios

## Сборка и изменения

- **Сегодня** показывает активное событие, подготовку к ближайшему событию, подходящую по длительности задачу или уход по времени суток. Таймер работает по времени устройства. С 23:00 до 07:00 действует ночной режим.
- **Календарь** использует чередование недель 3-ТТП-26 от 26 октября 2026 года. Дорога рассчитана от первой и последней посещаемой пары, а неполные дни исходного расписания помечены. Время вождения берётся из плана, дни можно менять. События можно повторять ежедневно, еженедельно или раз в две недели. Изменения повторяющегося события применяются ко всей серии. Вручную можно назначить время и задаче.
- **Проекты**: музыка для Fatt Mack, бизнес с одной оплаченной продажей до 31 декабря 2026, агенты Codex и методичка до 15 ноября, учёба. Старые квоты доступны в архиве. Настройка самих агентов остаётся отдельной работой по проекту.
- **Здоровье**: утро и вечер, еженедельный уход, дни зала, программа А/Б, прошлые подходы, питание с поиском и избранным, сон, шаги, вес, талия, кожа и даты фото. Фото отмечаются чек-листом. Личные ориентиры редактируются. Тестовые записи за 8 ноября сохранены и исключены из графиков и подсказок по предыдущим тренировкам.
- **Данные**: ключи 4.0 сохранены. JSON 5.0 включает события, задачи, заметки, настройки и журналы. Перед восстановлением сохраняется локальная копия прежних данных. Отчёты за 7 и 30 дней и импорт пакета задач доступны в настройках.

## Напоминания

Сейчас доступен ручной экспорт на 30 дней через **Настройки → Уведомления iPhone → Экспортировать .ics**. Для задач и событий со временем можно выбрать интервал напоминания. Импортируй файл в Календарь и проверь, что у события установлен сигнал. Повторный импорт может создать копии, поэтому для выгрузки удобен отдельный календарь. Изменения и удаление в GlowUp OS нужно перенести вручную. На физическом iPhone импорт и срабатывание сигнала ещё не проверялись.

### Как подключить Web Push

1. Оставить PWA на HTTPS. При запуске с домашнего экрана на iOS 16.4+ добавить кнопку «Включить уведомления», запрашивать разрешение по нажатию и создавать подписку через Push API. Service worker сборки уже умеет отображать входящие push и открывать приложение.
2. Добавить Cloudflare Worker, Cron Triggers и D1 в пределах бесплатных лимитов. При первоначальной настройке создать ключи VAPID. Приватный ключ держать в секрете Worker, публичный использовать в PWA. Закрыть маршруты подписок и очереди персональным токеном или входом, ограничить CORS адресом приложения.
3. Передавать на сервер подписку и выбранные пользователем напоминания. Хранить время отправки в UTC, стабильный ID события и состояние доставки. При изменении или удалении отменять старую запись. Принимать подписки только на разрешённые push-эндпойнты и удалять их при ответе 404/410. Cron выбирает записи с наступившим временем, ограничивает повторы и отправляет зашифрованный Web Push. Тексты уведомлений можно сделать нейтральными для экрана блокировки.
4. Проверить подписку, получение с заблокированным экраном, повтор и отмену на реальном iPhone. До такой проверки использовать .ics.

Документация: https://webkit.org/blog/13878/ · https://developer.apple.com/documentation/usernotifications/sending-web-push-notifications-in-web-apps-and-browsers · https://developers.cloudflare.com/workers/platform/limits/

## Проверки

Из папки распакованного проекта выполни `node tests/model.test.cjs` и `node tests/sw.test.cjs`. Они проверяют чтение старой базы, перенос всех трёх ключей, восстановление JSON v1/v2 и откат при сбое записи, расписание, конфликты, повтор, время и формат .ics. Для service worker использованы тестовые объекты браузерных API.

В Chrome пройдены все четыре вкладки, добавление, редактирование и удаление задач и событий, сохранение после перезагрузки, смена учебной недели, поиск еды, восстановление тестовой копии с задачей, событием и журналом. Встраиваемое окно 390 × 844 использовано для проверки светлой и тёмной тем и ширины формы. Safari, системная клавиатура, установка с «Домой», настоящий офлайн-запуск и доставка уведомлений на физическом iPhone требуют отдельного прогона.
